# RED THREAD — Requisitos do jogo (checklist de desenvolvimento)

Idioma: **português do Brasil** em todo o jogo. Nomes de pessoas fictícios.

## Base
- [ ] 3D top-down estilo Path of Exile (câmera inclinada, zoom, girar), build `.exe` único.
- [ ] Todas as pessoas com vida própria estilo Red Dead: casa, trabalho, rotina, família, relações, memória, fofoca.
- [ ] Mira de armas com o mouse, com alcance máximo por arma.
- [ ] Shift = correr (segurar), Alt = andar devagar, teclas remapeáveis no menu.
- [ ] Esc = menu com Salvar / Carregar / Ajustes.
- [ ] HUD minimalista (sem poluição).
- [ ] Cutscenes misteriosas; animações vivas.
- [ ] Música: trilhas por época (tema do Elias); locais com música (bares, pubs, hotéis, clubes, algumas casas) tocam variações sempre diferentes.

## Crime e mundo autônomo
- [ ] Invadir casas/estabelecimentos por porta (gazua/arrombar) ou janela (quebrar/forçar).
- [ ] Roubar itens e vender no mercado negro; vender carros, joias, tudo que tem valor.
- [ ] Matar, sequestrar, render, amarrar (Elias sempre tem corda).
- [ ] Pessoa amarrada/desaparecida gera boatos, família procura, polícia investiga.
- [ ] Roubar cidadão exige arma perigosa (faca etc.); render loja exige arma de fogo.
- [ ] Roubar carro: tirar a pessoa, quebrar vidro ou abrir fechadura; vítima foge, denuncia ou briga.
- [ ] Munição finita: comprar, achar, pegar de mortos armados; mortos deixam cair armas.
- [ ] Bolsa (inventário) para ver o que Elias carrega.
- [ ] Limpar a cena do crime (sangue, cápsulas, marcas) para não deixar rastro.
- [ ] Testemunhas, polícia com perfil, corpos, disfarces, identidades.

## Economia
- [ ] Dinheiro diferente em cada mundo (preços por época; libra em Adelaide).

## Conversa
- [ ] Tecla para conversar com qualquer pessoa; opções: amizade, romance, render, roubar, sequestrar, etc.

## Narrativa
- [ ] 30 casos em 6 eras, 3 camadas por caso, resolução falsa, linha do tempo alterada.
- [ ] Limbo que evolui, Outro Elias, finais A/B/C/D + QUEBRAR O FIO.
- [ ] Relacionamentos, casamento, filhos, ficar/partir, envelhecimento, diário, fadiga temporal.
- [ ] Rede de investigadores com tarefas, lealdade e traição.

## Adicionados depois
- [ ] Dublagem por sexo/idade, vozes nunca iguais; falas geradas (vítimas suplicam, amarrados pedem, execução → súplica), NPCs conversam entre si com áudio.
- [ ] Perseguição policial: polícia segue rastros/último local visto, vasculha; Elias pode se esconder, correr, render-se, trocar tiros, despistar.
- [ ] Cada cidade com estética, traçado, música, pessoas e polícia próprios (mapas nunca iguais).
- [ ] 12 cidades: Nova Orleans, Chicago, Vila na Baviera, Londres (Blitz), Adelaide, Berlim, Bergen, São Francisco, Portland, Nova York, Los Angeles, Nova Orleans 2001.
